
# 🍽️ Zomato Data Analysis

Welcome to **Zomato Data Analysis**, an interactive data exploration project that uncovers dining trends, pricing behaviors, and customer preferences from Zomato’s restaurant listings. This project uses **Tableau** to deliver visual, intuitive dashboards based on a cleaned and structured dataset.

---

## 🔍 Project Overview

Zomato is one of the most prominent platforms for restaurant discovery and food delivery. This project analyzes real restaurant data to answer questions like:

- What cuisines are the most expensive?
- How do customer ratings correlate with votes?
- Do high-end restaurants offer online delivery?
- What pricing tier do most restaurants fall under?

All analysis was visualized with **Tableau**, offering clear and compelling dashboards for better understanding and decision-making.

---

## 📁 Dataset Summary

The dataset includes various restaurant attributes, such as:

| Column Name              | Description                                    |
|--------------------------|------------------------------------------------|
| `Restaurant Name`        | Name of the restaurant                         |
| `Cuisines`               | Cuisine(s) offered                             |
| `Aggregate rating`       | Average user rating (0–5 scale)                |
| `Votes`                  | Number of customer votes                       |
| `Price range`            | Price tier (1 = Low, 4 = High)                 |
| `Has Online delivery`    | Online delivery availability (`Yes` / `No`)    |
| `Is delivering now`      | Real-time delivery status                      |
| `Average Cost for two`   | Typical cost for two people                    |

---

## 📊 Key Insights

These insights are based on Tableau dashboards created from the cleaned dataset:

- ⭐ **Ratings Distribution**: Most restaurants fall between **3.5 to 4.5 stars**, suggesting generally good service and food quality across the platform.
  
- 💸 **Costliest Cuisine**: **European cuisine** stands out as the most expensive on average.

- 🗳️ **Votes vs Ratings**: Higher-rated restaurants often receive more votes, but there are some notable exceptions—indicating that popularity isn't always about quality alone.

- 🚚 **Online Delivery**: A significant number of **high-cost and highly rated restaurants do not offer online delivery**, hinting at a premium dine-in focus.

- 🏷️ **Price Range Tiering**: The majority of restaurants fall into **Price Range 2** (moderate), showing a preference for affordability and accessibility in the market.
